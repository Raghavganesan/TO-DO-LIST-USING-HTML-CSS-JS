 <h1>📝 To-Do List Web App</h1>

 <p>A modern, responsive, and interactive To-Do List application built using <strong>HTML</strong>, <strong>CSS</strong>, and <strong>JavaScript</strong>. It includes features like editable tasks, checkbox-based completion, delete/clear options, and localStorage persistence.</p>

  <h2>🚀 Features</h2>
  <ul>
    <li>✅ Add new tasks with ease</li>
    <li>📝 Edit tasks in place</li>
    <li>🗑 Delete tasks individually</li>
    <li>🧹 Clear all tasks</li>
    <li>📌 Mark complete with checkboxes</li>
    <li>💾 Uses <code>localStorage</code> for saving tasks</li>
    <li>📱 Fully responsive design</li>
  </ul>

  <h2>📜 JavaScript – <code>features.js</code></h2>

  <p>This file contains the main logic of the To-Do List app, enabling all interactive features.</p>

<h3>🔧 Key Responsibilities:</h3>
<ul>
  <li><strong>Add tasks</strong>: Captures user input and appends it to the task list.</li>
  <li><strong>Mark tasks as completed</strong>: Using checkboxes to toggle completion and visually strike through.</li>
  <li><strong>Edit tasks</strong>: Double-click or use the ✏ button to edit existing tasks inline.</li>
  <li><strong>Delete tasks</strong>: Allows removal of individual tasks.</li>
  <li><strong>Clear all tasks</strong>: Deletes all tasks at once with a confirmation.</li>
  <li><strong>Persist tasks</strong>: Uses <code>localStorage</code> to save tasks across page refreshes.</li>
  <li><strong>Dynamic rendering</strong>: Updates the task list in real-time via <code>renderTasks()</code> function.</li>
  <li><strong>Event handling</strong>: Adds listeners for buttons, checkboxes, and keyboard interactions.</li>
</ul>
